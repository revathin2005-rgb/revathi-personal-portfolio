# Revathi Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript for a college HTML, CSS, and JavaScript fundamentals assignment.

## Features

- Responsive navigation with mobile hamburger menu
- Professional hero, about, skills, projects, and contact sections
- Project cards with technology tags and placeholder links
- Contact form with required field and email validation
- Success and error feedback messages
- Smooth scrolling and scroll-reveal animations
- Accessible navigation and live status messages

## Project Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
```

## Run the Website

Open `index.html` directly in a browser, or serve the folder locally with a simple web server:

```bash
cd portfolio
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- No real phone number or personal email address is included.
- GitHub and demo links use placeholder destinations.
- The profile image is represented by a professional initials-based placeholder.
- The project content describes student-level work and concepts without inventing achievements or credentials.
